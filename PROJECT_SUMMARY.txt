================================================================================
                         USAGE QUICK START
================================================================================

1. Install dependencies:
   $ pip install -r requirements.txt

2. Run application:
   $ python run.py
   # or
   $ python excel_lookup_gui.py

3. Test installation:
   $ python test_excel_lookup.py

4. Use the GUI:
   a. Select left Excel file (source)
   b. Select right Excel file (comparison)
   c. Choose sheets from both files
   d. Select key columns for matching
   e. Optionally select additional columns
   f. Click "Compare Data"
   g. Click "Save Results"

================================================================================
                         TECHNICAL DETAILS
================================================================================

Programming Language: Python 3.7+
GUI Framework: tkinter (standard library)
Data Processing: pandas (DataFrame operations)
Excel I/O: openpyxl (formatting support)
Architecture: Event-driven GUI
Design Pattern: Object-oriented (single class)

Key Classes:
   • ExcelLookupGUI - Main application class

Key Methods:
   • create_widgets() - GUI layout
   • browse_left_file() / browse_right_file() - File selection
   • on_left_sheet_selected() / on_right_sheet_selected() - Sheet loading
   • compare_data() - Comparison logic
   • save_results() - Output generation with formatting
   • reset_all() - State reset

Data Flow:
   File Selection → pandas → Sheet Loading → Column Population
        ↓
   Column Selection → Comparison Logic → Result DataFrame
        ↓
   Save Action → openpyxl → Formatted Excel Output
